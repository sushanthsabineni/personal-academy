REQUEST SUMMARY
================================================================================

Calculate approximate module duration based on selections from:
  • Step 1 (Essentials): Base duration, methodology, knowledge level
  • Step 2 (Multimedia): Course type, multimedia options, quiz strategy
  
Display as "Approx: X minutes" in:
  • Top stats badge (total duration)
  • Individual module duration cards
  • Throughout Step 3 (Modules Management)

================================================================================
ALGORITHM OVERVIEW
================================================================================

Formula:
  Total Duration = Base × CourseTypeMultiplier × MediaOptionsMultiplier × QuizMultiplier

Multipliers:
  Course Type:        Simple (1.0x) → Scenario-Driven (1.50x)
  Multimedia Options: +5% to +20% per selection (audio, video, images, assessments, animation)
  Quiz Strategy:      +5% to +20% depending on frequency

Example Results:
  • Simple text-based:                        ~34 minutes
  • Interactive with audio:                   ~52 minutes
  • Highly interactive with video:            ~117 minutes
  • Scenario-driven with all options:         ~119 minutes

Per-Module Duration: Total ÷ Number of Modules

================================================================================
KEY DECISIONS
================================================================================

1. CALCULATION BASIS
   → Use Step 1 base duration as foundation
   → Multiply by complexity factors (type, multimedia, quiz)
   → Provides intuitive, predictable results

2. STORAGE
   → Don't persist (calculated/derived from selections)
   → Recalculate on every load
   → Updates automatically if user changes selections

3. DISPLAY FORMAT
   → "Approx: X minutes" (indicates estimate)
   → Round to nearest 1 minute
   → Consistent across all displays

4. PER-MODULE DISTRIBUTION
   → Total ÷ Module Count
   → Proportional and fair
   → Recalculates if module count changes

5. FALLBACK STRATEGY
   → Use sensible defaults if Step 2 data unavailable
   → Provide "Approx: X (estimated)" label
   → Still show calculation, don't fail
